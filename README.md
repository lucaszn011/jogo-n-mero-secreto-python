# Jogo do Número Secreto

Jogo simples feito em Python. O computador escolhe um número aleatório entre 5 e 50, e o jogador tem até três tentativas para acertar.

## Tecnologia

- Python

## O que pratiquei

- Geração de números aleatórios
- Entrada de dados
- Condicionais
- Laços de repetição
- Tratamento de entrada inválida

## Como executar

No terminal, execute:

```bash
python lucas.py
```
