# Jogo do Número Secreto

Projeto simples desenvolvido em Python como exercício de lógica de programação.

O computador sorteia um número entre 5 e 50, e o jogador tem até três tentativas para descobrir qual é. A cada palpite, o programa informa se o número secreto é maior ou menor.

## Tecnologia

- Python

## Conceitos praticados

- Geração de números aleatórios com `random`
- Entrada de dados com `input`
- Conversão de valores com `int`
- Estruturas condicionais (`if`, `elif` e `else`)
- Laço de repetição (`for`)
- Tratamento de entrada inválida com `try/except`

## Como executar

É necessário ter Python instalado.

No terminal, acesse a pasta do projeto e execute:

```bash
python lucas.py
```

## Arquivo principal

- `lucas.py`: contém a lógica do jogo.
